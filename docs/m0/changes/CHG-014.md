# YP-M0-CHG-014 · bootstrap/preflight 默认目标 UID 改为镜像 JENKINS_UID

| 项 | 值 |
|---|---|
| 文档编号 | YP-M0-CHG-014 |
| 状态 | Approved |
| 提出日期 | 2026-11-26 |
| 批准人 | zeek.zhao |
| 关联 | YP-M0-ISS-022 |

## 1. 变更内容

- 变更前：`bootstrap.sh` / `preflight.sh` 的 `TARGET_UID/TARGET_GID` 默认取当前宿主用户 `id -u/id -g`（T4 契约）。
- 变更后：默认取 `scripts/cache/threshold.conf` 的 `JENKINS_UID/JENKINS_GID`（1000:1000），与 builder 镜像 `jenkins` 用户对齐。仍可用 `--uid/--gid` 显式覆盖；非 root 且目标与当前用户不一致仍 exit 2 给 sudo / 重建镜像两条路径；root 执行视为 sudo 路径，允许 chown（root 仍可写）。

## 2. 为什么要改

- 本轮 HEAD `88246d0` 在 root(uid=0) 宿主上实测：不带 `--uid` 的隔离探针 exit 0 但卷属主为 `0:0`（ISS-022）。builder 镜像 `jenkins/1000` 的 entrypoint 要求挂载点属主 UID=1000，默认卷会导致容器入口拒绝启动。镜像构建用户固定为 jenkins/1000（约束 7），故默认隐式目标必须与之对齐。

## 3. 影响面

| 维度 | 影响 |
|---|---|
| 变量与契约 | 默认值从“当前用户”改为 `JENKINS_UID/JENKINS_GID`（仍来自唯一源 threshold.conf）；`--uid/--gid` 覆盖不变 |
| 目录与脚本 | `scripts/bootstrap.sh`、`scripts/preflight.sh` 的 TARGET 默认值行；`docs/runbook-new-machine.md` §5.2 契约描述 |
| 门禁 | 无新阈值；`check-vars.sh` 对 `JENKINS_UID` 的断言不变；gate G2 不受影响 |
| 已产出的镜像 / 缓存 | 不改镜像、不改已发布 release 分片；仅新机器初始化默认行为 |

## 4. 回滚方式

- 回滚命令：`git revert <本提交>`；把两脚本 TARGET 默认值改回 `id -u/id -g`，runbook §5.2 同步还原。
- 回滚后如何验证：root 宿主不带 `--uid` 探针应回到 `0:0`（即复现 ISS-022），确认回滚生效。

## 5. 验证方式

```bash
# 修复后 root 宿主不带 --uid 的隔离探针
rm -rf /tmp/uid-probe2 && mkdir -p /tmp/uid-probe2
bash scripts/bootstrap.sh --downloads /tmp/uid-probe2/dl --sstate /tmp/uid-probe2/sstate --min-free-bytes 0
# 期望 WARN SUDO_PATH + CHOWN ... -> 1000:1000，PROBE_EXIT=0
stat -c '%u:%g %n' /tmp/uid-probe2/dl /tmp/uid-probe2/sstate   # 1000:1000
bash scripts/preflight.sh --downloads /tmp/uid-probe2/dl --sstate /tmp/uid-probe2/sstate   # OK owner=1000
bash scripts/gate.sh && bash scripts/check-vars.sh   # GATE_PASS / VARS_OK
```
