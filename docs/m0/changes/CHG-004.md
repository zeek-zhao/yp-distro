# YP-M0-CHG-004 · CI edition 移除图形栈 DISTRO_FEATURES 以缩小最小构建

| 项 | 值 |
|---|---|
| 文档编号 | YP-M0-CHG-004 |
| 状态 | Approved |
| 提出日期 | 2026-11-25 |
| 批准人 | zeek.zhao |
| 关联 | YP-M0-DES-002 §3.5（ci edition = 最小构建、缓存命中优先）/ YP-M0-DES-005 / YP-M0-ISS-010 |

## 1. 变更内容

`kas/editions/ci.yml` 的 `local_conf_header.ci` 新增一行：

```bitbake
# 最小构建：继承 poky 基线时默认带入 opengl/x11 等图形特性，
# 会把 mesa→llvm→clang 拉进 core-image-minimal 的依赖树（llvm 源码包 167M）
DISTRO_FEATURES:remove = "opengl x11 wayland vulkan"
```

## 2. 为什么要改

- DES-002 §3.5 定义 ci edition 为「最小构建、缓存命中优先」，但实际解析出 **4630 任务**，包含 `llvm-project-source`（167M 源码包）、wayland 等图形栈——与「最小」不符。
- `yp-wrynose.conf` `require conf/distro/poky.conf`，其默认 `DISTRO_FEATURES` 含 `opengl`；qemux86-64 机器特性含 `vga`，两者组合触发 mesa 构建并级联 llvm/clang。
- ISS-010 三轮重试中，随机中断点都发生在巨型源码包 `do_unpack`（llvm → gcc → linux-libc-headers），裁掉图形栈可直接减少高风险大包数量，缩小构建面。
- 该变更只作用于 ci edition（其他 edition 不受影响），且不触碰 repos/commit pin、缓存服务器禁令与挂载契约。

## 3. 影响面

| 维度 | 影响 |
|---|---|
| 构建规模 | 依赖树缩小，任务数与巨型包数量下降；`core-image-minimal` 产物内容不变 |
| 命中率 | sstate 现有对象按新配置重算，首轮命中可能低于修复前 43%，属预期 |
| kas 配置 | 仅 ci.yml 一行；base.yml 与其他 edition 不变 |
| 门禁 | S8 可校验 ci.yml 含图形特性裁剪行 |

## 4. 回滚方式

- 回滚命令：删除 ci.yml 中该行。
- 回滚后如何验证：`kas dump kas/yp.yml:kas/editions/ci.yml` 输出不再含 `DISTRO_FEATURES:remove`；构建规模回到 4630 任务。

## 5. 验证方式

```bash
docker exec kas-build bash -c 'cd /work/build-run && kas dump kas/yp.yml:kas/editions/ci.yml | grep "DISTRO_FEATURES"'
# 构建日志中不应再出现 llvm-project-source 的 do_unpack 任务
grep -c "llvm-project-source" /work/measure-logs/first.log
```
