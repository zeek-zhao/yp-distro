## 1. 变更内容

- 变更前：
  - `docker/cache-meta.json` 只有布局、阈值与 `note: "Baseline layout only"`，没有 edition/machine/kas commit/载荷哈希/文件数/生成时间；
  - GHCR 全量分片消费所需的 `manifest.json` 只在 CI artifact（会过期），release `m0-s5-payload-full` 没有 slice manifest 资产；
  - `gen-meta.sh` 输出不含 provenance，`gate.sh` G2 只比对布局与阈值。
- 变更后：

| 契约项 | 新值 |
|---|---|
| provenance 文件 | `docker/cache-provenance.json`，静态入库，不由时间戳动态生成 |
| provenance 字段 | `edition=ci`、`machine=qemux86-64`、`distro=yp-wrynose`、`distro_version=0.1.0`、4 个 kas repo commit、`payload_sha256=1c8126d4…`、`payload_bytes=11153397760`、`file_counts.downloads=1288`、`file_counts.sstate=6945`、`created_at` 固定字符串、`source="S5 full build"` |
| gen-meta 契约 | 读取静态 provenance 并合并进输出；文件缺失即报错；同样输入逐字相同，保证 `gate.sh` G2 仍比对通过 |
| cache-meta note | 由 `Baseline layout only` 改为「真实 S5 载荷；分片分发见 ADR-005/CHG-012/CHG-013」 |
| 清单持久化 | `manifests/full-slices-manifest.json` 作为 `cache-full.manifest.json` 上传 release `m0-s5-payload-full`；`scripts/cache/publish-manifest.sh` 支持 `--dry-run`，无凭据时明确提示 `GH_TOKEN`，不伪造成功 |

## 2. 为什么要改

- 换机时无法从 `cache-meta.json` 判断缓存是哪个 edition/machine/kas commit 产出的，也无法核对载荷哈希与文件数。
- CI artifact 会过期，GHCR 全量分片一旦脱离 CI 就没有可持久引用的 manifest，消费端无法用 `merge.sh` 校验。
- `gate.sh` G2 逐字比对 `gen-meta.sh` 输出与 `docker/cache-meta.json`，所以 provenance 必须是静态文件，不能用 `date` 动态生成。

## 3. 影响面

| 维度 | 影响 |
|---|---|
| 变量与契约 | 不改 `threshold.conf`；新增 provenance 静态文件与 `cache-meta.json` 的 `provenance` 段 |
| 目录与脚本 | 改 `gen-meta.sh`；新增 `docker/cache-provenance.json`、`scripts/cache/publish-manifest.sh`、`manifests/full-slices-manifest.json` |
| 门禁 | `gate.sh` 五项不变；G2 比对对象随 `cache-meta.json` 重新生成后仍须 `GATE_PASS` |
| 已产出的镜像 / 缓存 | 不改已发布 tag 与分片；只补元数据与清单 |

## 4. 回滚方式

- 回滚命令：`git revert <本提交>`；删除 `docker/cache-provenance.json` 与 `scripts/cache/publish-manifest.sh`，重新生成旧版 `cache-meta.json`。
- 回滚后验证：`bash scripts/gate.sh` → `GATE_PASS`，`docker/cache-meta.json` 无 `provenance` 段。

## 5. 验证方式

```bash
bash scripts/cache/gen-meta.sh                 # 输出含 provenance，重复两次 diff 为空
bash scripts/gate.sh                           # GATE_PASS
bash scripts/check-vars.sh                     # VARS_OK checked=28 drift=0
bash scripts/cache/publish-manifest.sh --dry-run --release-tag m0-s5-payload-full
```
