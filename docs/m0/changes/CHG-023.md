## 1. 变更内容

### 1.1 `scripts/ai-entry.sh`：完成态前缀判定（ISS-041）

- 变更前：`if (state != "完成")`，带注记的完成态（`完成（…）` / `完成 / …`）被当成未完成。
- 变更后：`done = (state ~ /^完成/ || state ~ /^已验/); if (!done) {...}`。
- 覆盖：`完成`、`完成（Stage E 接线 + 契约收紧）`、`完成 / 端到端已验`、`完成（…）`、`已验…`。
- 边界：`^完成` 不匹配 `未完成`（首字非「完成」），不误判。

### 1.2 `--next` 无后续 Step 分支

- 变更前：`next_row` 为空仍 `read` 到空变量并打印「继续 M0：实现 Step （）」。
- 变更后：`[ -z "$next_row" ]` 时输出
  `M0 全部 Step 已完成；M0.1 已闭环；M1 未立项，先补 M1 范围/PRD 评审，不直接写 M1 代码。`，exit 0。

### 1.3 普通模式完成态输出

- 变更前：`下一步   : 全部 Step 已完成，转入验收（YP-M0-REC-001）`。
- 变更后：
  - `下一步   : M0/M0.1 已闭环；M1 未立项（需 PRD/范围评审）`
  - `取提示词 : 先写 M1 范围，再拉 feat-m1-*`

### 1.4 可测试性

- `PLAN="${PLAN_OVERRIDE:-$ROOT/docs/m0/plan.md}"`：允许用临时 plan 验证状态解析；正常路径输出语义不变。
