## 2. 为什么要改

- 事实依据（AI-007 §1 只读复现）：
  - README:51 唯一裸 bootstrap；uid1234 默认 bootstrap exit 2 `UID_MISMATCH`、显式 `--uid/--gid` bootstrap+preflight exit 0、root `--uid 1000` exit 0。
  - README:7/39、runbook:11「只装/只需要 Docker」；宿主实际依赖 git/bash/python3/curl/tar/sha256sum 均存在（本机路径已记录）；verify-env:136 缺 python3 会误报 registry 401。
  - test prompt:143 `docker run --rm ghcr.io/...`，路径 B 会验错镜像；runbook:153 有 IMAGE 变量但无跨 shell 注；§4 DEST_PARENT 无边界。
