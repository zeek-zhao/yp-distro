| 关联 | ISS-014、DES-007、DES-008、CHG-007 |
| 影响阶段 | S5（载荷上传方）、S7（分片发布方）、判据 7 |

## 1. 变更内容

- 变更前：`publish-cache-slices` 从仓库变量或仓库内 `./cache-payload/{downloads,sstate}` 取载荷（该目录不存在）；manifest 仅打印到 step summary；push/inspect 失败用 `echo 'push-ok'` 兜底。
- 变更后：

| 契约项 | 新值 |
|---|---|
| S5 载荷制品名 | `cache-payload`（由 S5 上传，内容须含顶层 `downloads/` 与 `sstate/`，且各至少有一个文件） |
| 获取方式 | `actions/download-artifact@v4` → `${{ runner.temp }}/s5-payload`；下载失败或目录缺失/为空即 `::error` + exit 1 |
| 仓库内回退路径 | **删除**（禁止用不存在的 `./cache-payload` 冒充） |
| digest 来源 | 仅 `docker buildx imagetools inspect <tag>` 的 `Digest:` 行；push/inspect/空 digest 任一失败即 job 红，删除 `|| echo 'push-ok'` |
| 清单制品 | `actions/upload-artifact@v4`，名称 `yp-cache-slices-manifest`，路径 `/tmp/slices/manifest.json`，`if-no-files-found: error` |
| step summary | 必须包含制品名与逐片 `<tag> <digest>` 行 |

## 2. 为什么要改

- 事实依据：ISS-014 记录的仓库内无 `cache-payload` 目录、`docker push ... || echo 'push-ok'` 会把失败写成 `push-ok`、manifest 无制品。发布端到端结论此前无法由真实证据支撑。
- CHG-007 已使 push 触发可用；本变更补齐「有载荷才发布、失败即停」的另一半。

## 3. 影响面

| 维度 | 影响 |
|---|---|
| 变量与契约 | 新增制品名 `cache-payload`、`yp-cache-slices-manifest`；删除 vars 回退；阈值常量不变 |
| 目录与脚本 | 仅 `.github/workflows/m0.yml` 的 `publish-cache-slices` job；`scripts/cache/*` 不改 |
| 门禁 | `gate.sh`/`check-vars.sh` 不变；判据 7 的发布结论改为由真实 run 决定 |
| 已产出的镜像 / 缓存 | 无；既有 GHCR tag 不被改写 |

## 4. 回滚方式

- 回滚命令：`git revert <本提交 SHA>`；恢复 vars/本地路径回退与 `push-ok` 兜底（不推荐，仅供审计对比）。
- 回滚后如何验证：`git grep 'push-ok'` 有命中、`git grep 'cache-payload'` 命中本地默认路径、无 `yp-cache-slices-manifest` 上传步骤。

## 5. 验证方式

```bash
# 本地静态验证（无需 GHCR）
python3 - <<'PY'
import yaml
w = yaml.safe_load(open('.github/workflows/m0.yml'))
s = w['jobs']['publish-cache-slices']['steps']
names = [x.get('name','') for x in s]
assert any('download-artifact' in str(x.get('uses','')) for x in s)
assert any(x.get('with',{}).get('name') == 'yp-cache-slices-manifest' for x in s)
print('WORKFLOW_STEPS_OK', len(names))
PY
grep -n "echo 'push-ok'" .github/workflows/m0.yml || echo 'PUSH_OK_FALLBACK_REMOVED'
grep -n "'./cache-payload" .github/workflows/m0.yml || echo 'LOCAL_PAYLOAD_FALLBACK_REMOVED'
```
