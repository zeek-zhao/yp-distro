## 1. 变更内容

- 变更前：`docker/Dockerfile` 中 `RUN pipx install kas`（无版本号，随 pip 最新漂移）
- 变更后：`RUN pipx install kas==5.5`（精确版本，注释说明锁定原因）

## 2. 为什么要改

- 实测容器内 `kas --version` = `kas 5.5 (configuration format version 23)`；无版本安装会在镜像重建时拉取更新版本，可能改变 dump 输出格式，破坏 B-02「两次 dump 一致」与可复现性（RV-010 F-06）。
- 依赖基线变更需 CHG 记录，不静默改。

## 3. 影响面

| 维度 | 影响 |
|---|---|
| 变量与契约 | kas 版本成为固定契约 5.5，写入 variable-index.md（S9） |
| 目录与脚本 | 仅 Dockerfile 第 2 节一行 |
| 门禁 | S8 可加 `kas --version` 断言 = 5.5 |
| 已产出的镜像 / 缓存 | 需重建 builder 镜像使锁定生效；本次验收用现有 5.5 镜像（已是目标版本） |

## 4. 回滚方式

- 回滚命令：把 Dockerfile 改回 `RUN pipx install kas`
- 回滚后如何验证：`docker build` 后 `kas --version` 可返回任意版本（即未锁定状态）

## 5. 验证方式

```bash
docker run --rm ghcr.io/zeek-zhao/yp-builder:wrynose-m0 kas --version
# 期望：kas 5.5 (configuration format version 23, earliest compatible version 1)
```
