## 1. 变更内容

| 契约项 | 变更前 | 变更后 |
|---|---|---|
| 规范性 kas 命令 | 混用 `kas/yp.yml:kas/editions/<n>.yml`、`kas/yp.yml:edition/prod.yml:machine/...` | 统一为 `kas/yp.yml:editions/<n>.yml`（仓库根执行） |
| 目录映射 | 只有 `kas/editions/` | 根级符号链接 `editions -> kas/editions`（ISS-015 实测简写 rc=0） |
| 历史证据 | ISS-007/ISS-008/RV-005 中已执行命令原文 | **不改写**；只在 DES-002/CHG/ISS 中说明规范性写法已变更 |
| G2 阈值检查 | grep 模式含字面量 `8589934592`，并排除 `gate.sh`、`check-vars.sh` 自身 | `gate.sh` source `threshold.conf`，用变量拼 grep 模式；不再排除 `check-vars.sh`（也不再需要排除 `gate.sh`） |
| check-vars 阈值期望串 | 4 条规则写死阈值数字 | source `threshold.conf` 后用 `${SLICE_MAX_BYTES}` 等变量拼期望串 |

- G2 的扫描范围仍为 `scripts/` 与 `.github/`；检测对象为**两项切分阈值**（`SLICE_MAX_BYTES`、`UPLOAD_TIMEOUT_SEC`）。`JENKINS_UID`/`MIN_FREE_BYTES` 属挂载预检契约，由 check-vars 用变量断言，不纳入 G2 数值扫描，以免与 `m0.yml` 中合法的 `build-args JENKINS_UID=1000` 混淆。

## 2. 为什么要改

- ISS-015：要求的简写命令在原布局下 rc=2；仅改文档字符串会让 README/验收命令不可执行。
- 约束 8 与 ISS-012：阈值唯一源必须真成立；此前 `gate.sh` 与 `check-vars.sh` 因自身含阈值字面量而被 G2 自我豁免，属"检查逻辑例外"，并非真正唯一源。

## 3. 影响面

| 维度 | 影响 |
|---|---|
| 变量与契约 | 规范性 kas 命令改写；阈值数值仍只在 `scripts/cache/threshold.conf` 定义，门禁与检测脚本改为引用变量 |
| 目录与脚本 | 新增根级 `editions` 符号链接；`scripts/build/measure.sh`、`scripts/gate.sh`、`scripts/check-vars.sh` 修改 |
| 门禁 | G2 删除自我豁免；`gate.sh` 五项仍需 `GATE_PASS`，`check-vars.sh` 仍需 `VARS_OK drift=0` |
| 已产出的镜像 / 缓存 | 无；不改 GHCR tag、不改卷内容 |

## 4. 回滚方式

- `git revert <本提交 SHA>`，删除根级 `editions` 符号链接；规范性命令回到 `kas/yp.yml:kas/editions/<n>.yml`，G2/check-vars 恢复字面量与自我豁免。
- 回滚后验证：`grep -rn '8589934592' scripts/check-vars.sh` 有命中；`test -L editions` 为 false；`kas dump kas/yp.yml:editions/prod.yml` rc=2。

## 5. 验证方式

```bash
# 干净检出 + 简写 dump 稳定性
TMP=$(mktemp -d); git checkout-index --prefix="$TMP/" -a
(cd "$TMP" && kas dump kas/yp.yml:editions/prod.yml >/tmp/d1.yml && \
 kas dump kas/yp.yml:editions/prod.yml >/tmp/d2.yml && diff -u /tmp/d1.yml /tmp/d2.yml && echo DUMP_STABLE)
# 阈值唯一源：脚本侧无阈值字面量
grep -rnE '8589934592|480' scripts/ .github/ | grep -v '^scripts/cache/threshold.conf:' || echo THRESHOLD_LITERALS_ONLY_IN_CONF
bash scripts/gate.sh        # GATE_PASS
bash scripts/check-vars.sh  # VARS_OK drift=0
```
