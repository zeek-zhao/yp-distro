## 1. 现象（只写观察到的事实）

- 观察到的输出／现象：在本轮机器（当前用户 `root`，`uid=0 gid=0`）执行不带 `--uid/--gid` 的 `bootstrap.sh`，隔离探针 exit 0，但两个卷被建为 `0:0`：
  ```
  INIT  downloads marker=/tmp/uid-probe/dl/.yp-volume
  OWNER_OK /tmp/uid-probe/dl (0:0)
  INIT  sstate marker=/tmp/uid-probe/sstate/.yp-volume
  OWNER_OK /tmp/uid-probe/sstate (0:0)
  PROBE_EXIT=0
  stat: 0:0 /tmp/uid-probe/dl ; 0:0 /tmp/uid-probe/sstate
  ```
  builder 镜像内用户为 `jenkins/1000`，`docker/entrypoint.sh` 校验挂载点属主 UID 必须等于 1000，否则拒绝启动。用该默认卷构建会在容器入口阶段失败。
- 影响范围：S4 挂载初始化；所有当前 UID≠1000 且不带显式 `--uid/--gid` 的新机器；不影响已发布镜像与缓存产物本身。

## 2. 复现

```bash
# HEAD 88246d0，镜像 ghcr.io/zeek-zhao/yp-builder:wrynose-m0 (sha256:a269f5e7…)
id -u   # 0
rm -rf /tmp/uid-probe && mkdir -p /tmp/uid-probe
bash scripts/bootstrap.sh --downloads /tmp/uid-probe/dl --sstate /tmp/uid-probe/sstate --min-free-bytes 0
echo "PROBE_EXIT=$?"          # 0
stat -c '%u:%g %n' /tmp/uid-probe/dl /tmp/uid-probe/sstate   # 0:0 ...
```

- 期望结果：默认目标应为镜像 `JENKINS_UID`；非 root 且当前 UID≠1000 时 exit 2 并给出 sudo / 重建镜像两条路径；root（sudo 路径）应把卷 chown 到 1000:1000。
- 实际结果：默认目标取当前用户 `0:0`，root 路径未触发 `WARN SUDO_PATH`，卷保持 `0:0`。
- 首次出现于：提交 `85f0b24` 之前的 T4（RV-013 追加记录 T4）确立「默认取当前用户」契约时引入；本轮 HEAD `88246d0` 实测复现。

## 3. 根因分析（Analyzed 阶段填写）

- 直接原因：`bootstrap.sh`、`preflight.sh` 中 `TARGET_UID="$CURRENT_UID"`、`TARGET_GID="$CURRENT_GID"`，默认值取当前宿主用户而非镜像默认 `JENKINS_UID/JENKINS_GID`。
- 根本原因：T4 为兼容非 1000 用户把默认目标改为“当前用户”，但镜像内构建用户固定 `jenkins/1000`；当宿主当前 UID≠1000 且调用方未显式传 `--uid/--gid` 时，卷属主与容器期望不一致。
- 排除过的假设及排除依据：不是 chown 权限问题（root 可写）；不是 entrypoint 缺陷（其行为符合 DES-003/B-04 设计，校验属主 UID==1000 是正确的）。

| 类型 | 内容 | 责任人 | 何时执行 |

| 临时措施（止痛） | 本轮构建统一走路径 A：所有 bootstrap/preflight 显式带 `--uid 1000 --gid 1000` | zeek.zhao | 本轮 |

## 5. 验证证据（Verifying 阶段填写）

```bash
# HEAD 88246d0 + CHG-014，root 宿主，不带 --uid
rm -rf /tmp/uid-probe2 && mkdir -p /tmp/uid-probe2
bash scripts/bootstrap.sh --downloads /tmp/uid-probe2/dl --sstate /tmp/uid-probe2/sstate --min-free-bytes 0
# WARN SUDO_PATH current=0:0 target=1000:1000
# CHOWN /tmp/uid-probe2/dl -> 1000:1000 ; CHOWN .../sstate -> 1000:1000 ; PROBE_EXIT=0
stat -c '%u:%g %n' /tmp/uid-probe2/dl /tmp/uid-probe2/sstate
# 1000:1000 /tmp/uid-probe2/dl ; 1000:1000 /tmp/uid-probe2/sstate
bash scripts/preflight.sh --downloads /tmp/uid-probe2/dl --sstate /tmp/uid-probe2/sstate
# OK role=downloads owner=1000 writable=yes ; OK role=sstate owner=1000 writable=yes ; PF_EXIT=0
bash -n scripts/bootstrap.sh && bash -n scripts/preflight.sh   # SYNTAX_OK
```

- 结论：通过（默认目标已对齐镜像 1000:1000，root 路径 chown 成功且仍可写）
