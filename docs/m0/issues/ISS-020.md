## 1. 现象（只写观察到的事实）

- 本地按 workflow 同一命令构建并推送全量分片：
  - `ghcr.io/zeek-zhao/yp-cache:wrynose-m0-full-part-00` → `BUILD_OK`、`PUSH_OK`、`DIGEST sha256:f1404012d98fb7956619aa4c89b293a435a322b67fcc57227b1c15baef974390`
  - `ghcr.io/zeek-zhao/yp-cache:wrynose-m0-full-part-01` → `BUILD_OK`，`docker push` 输出：

```text
The push refers to repository [ghcr.io/zeek-zhao/yp-cache]
5488100e162b: Preparing
08bc4e534116: Preparing
08bc4e534116: Layer already exists
unknown blob
```

- 分片 01 大小 2,563,463,168 B（约 2.39 GiB）；分片 00 大小 8,589,934,592 B（8 GiB）已成功。
- 未产生分片 01 的 digest；脚本按失败即停退出，没有把失败写成成功。

```bash
docker build -f /tmp/full-slice-01/Dockerfile -t ghcr.io/zeek-zhao/yp-cache:wrynose-m0-full-part-01 /tmp/full-slice-01
```
