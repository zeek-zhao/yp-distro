# YP-M0-ISS-003 · Docker build 创建 jenkins 用户时 GID 1000 冲突

| 项 | 值 |

## 1. 现象（只写观察到的事实）

- 观察到的输出／现象：`docker build ... -t yp-builder:wrynose-m0 docker/` 在第 4 层失败，输出
  `groupadd: GID '1000' already exists`，exit code 4。
- 影响范围：S3 镜像无法构建；不影响设计正确性。

## 2. 复现

```bash
cd /workspace/yp-distro
docker build --build-arg JENKINS_UID=1000 --build-arg JENKINS_GID=1000 \
  -t yp-builder:wrynose-m0 docker/
# 失败于 [4/7] groupadd: GID '1000' already exists

docker run --rm ubuntu:24.04 bash -c 'getent group 1000; getent passwd 1000'
# ubuntu:x:1000:   /   ubuntu:x:1000:1000:Ubuntu:/home/ubuntu:/bin/bash
```

- 期望结果：成功创建 `jenkins` 用户（UID/GID=1000）。
- 实际结果：基础镜像自带 `ubuntu` 用户/组占用了 UID/GID 1000，`groupadd` 拒绝重复 GID。
- 首次出现于：提交工作区 S3 Dockerfile 初稿 / 镜像 `ubuntu:24.04`（digest `sha256:562111b8...`）。

## 3. 根因分析（Analyzed 阶段填写）

- 直接原因：`ubuntu:24.04` 官方镜像预置 `ubuntu` 用户与同名组，UID/GID 均为 1000；Dockerfile 默认 build-arg 也是 1000，创建 `jenkins` 时 GID 冲突。
- 根本原因：Dockerfile 未考虑基础镜像已占用默认 UID/GID 的情况，缺少「先释放再创建」的幂等处理。
- 排除过的假设：非 Docker 守护进程问题（前 3 层正常完成）；非 apt/pipx 问题（kas 5.5 已成功安装）。

## 4. 措施

| 类型 | 内容 | 责任人 | 何时执行 |
|---|---|---|---|
| 临时措施（止痛） | 无（直接做永久措施） | — | — |
| 永久措施（治因） | Dockerfile 在创建 jenkins 前，若 UID/GID 已被非 jenkins 用户/组占用，则先删除镜像自带的 `ubuntu` 用户/组；用 `groupadd -o`（允许非唯一 GID 回退）或条件判断保证幂等，使任意 build-arg 取值均可构建 | zeek.zhao | 2026-11-24 |

- 后续项：无。

## 5. 验证证据（Verifying 阶段填写）

```bash
cd /workspace/yp-distro
docker build --build-arg JENKINS_UID=1000 --build-arg JENKINS_GID=1000 \
  -t yp-builder:wrynose-m0 docker/     # 期望：构建成功
docker run --rm yp-builder:wrynose-m0 whoami   # 期望：jenkins
docker run --rm yp-builder:wrynose-m0 id -u    # 期望：1000
docker build --build-arg JENKINS_UID=2000 --build-arg JENKINS_GID=2000 \
  -t yp-builder:wrynose-m0-uid2000 docker/     # 期望：构建成功
docker run --rm yp-builder:wrynose-m0-uid2000 id -u  # 期望：2000
```

- 结论：通过。真实输出（2026-11-24）：
  - `docker build ... -t yp-builder:wrynose-m0`（UID=1000）→ `naming to docker.io/library/yp-builder:wrynose-m0 done`，镜像 `ba1a5b8b7ecf`（589MB）；
  - `docker build ... -t yp-builder:wrynose-m0-uid2000`（UID=2000）→ `naming to ... uid2000 done`，镜像 `b6fead9b8f91`；
  - `docker run --rm yp-builder:wrynose-m0 whoami` → `jenkins`；`id -u` → `1000`；`kas --version` → `kas 5.5`；
  - `docker run --rm yp-builder:wrynose-m0-uid2000 id -u` → `2000`；
  - 正确属主挂载 → exit 0 放行；错属主挂载 → exit 1；覆盖 root → exit 1。

## 6. 关闭

- 关闭条件：修复后两条 build（默认 UID 与 UID=2000）均成功，且 whoami/id -u 输出符合预期。
- 关闭人 / 日期：zeek.zhao / 2026-11-24
- **下次如何避免**：写 Dockerfile 创建固定用户前，先用 `getent passwd <uid>` / `getent group <gid>` 检查官方基础镜像的占用情况；用条件删除或 `-o` 选项保证 build-arg 任意取值下幂等。
