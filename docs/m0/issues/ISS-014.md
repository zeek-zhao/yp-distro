## 1. 现象（只写观察到的事实）

- `.github/workflows/m0.yml` 的 `publish-cache-slices` 步骤 `Prepare cache source from S5 payload` 使用 `vars.YP_CACHE_DOWNLOADS_DIR || './cache-payload/downloads'` 与 `vars.YP_CACHE_SSTATE_DIR || './cache-payload/sstate'`；全仓 `grep -rn 'cache-payload'` 仅命中该 workflow 与 CHG-007 文档，**仓库内不存在 `cache-payload/` 目录**，也没有任何 S5 上传该目录的 workflow 记录。
- 同一步在目录缺失时打印 `::error::...` 后 `exit 1`——该部分行为本身正确，但默认值指向不存在的路径，等于把「没有载荷」写成「可能有载荷」。
- `Publish each slice as a GHCR tag + upload manifest` 步骤中：

```bash
digest="$(docker push "$tag" >/dev/null 2>&1 && docker buildx imagetools inspect "$tag" 2>/dev/null | grep -m1 'Digest:' | awk '{print $2}' || echo 'push-ok')"
```

`docker push` 失败（或 `imagetools inspect` 失败、或 grep 无匹配）时，`digest` 被写成字面量 `push-ok`，summary 仍显示该片「发布成功」。
- manifest.json 只在 step summary 里 `cat`，没有作为制品上传；发布后无法单独取回清单。

## 2. 复现

```bash
cd /workspace/yp-distro
git grep -n 'cache-payload'                 # 只有 workflow 默认值；无对应目录/上传步骤
git grep -n "echo 'push-ok'"                # 命中 publish-cache-slices
python3 - <<'PY'
import yaml
w = yaml.safe_load(open('.github/workflows/m0.yml'))
steps = w['jobs']['publish-cache-slices']['steps']
print([s['name'] for s in steps])
PY
```

- 期望结果：载荷来自 S5 上传的具名制品，取不到则失败；push/inspect 失败即 job 红；manifest 作为具名制品可下载。
- 实际结果：默认本地路径不存在；失败被 `push-ok` 掩盖；manifest 无制品。

## 3. 根因分析

- 直接原因：workflow 在 S5 产物尚未接入 GitHub Actions 制品时，用仓库内占位路径作默认值；digest 采集用 `|| echo 'push-ok'` 兜底。
- 根本原因：S7「接线阶段」把「脚本链路可用」与「CI 发布端到端可验」混写，缺少明确的载荷契约（制品名、目录结构）和失败即停语义。
- 排除过的假设：不是 GHCR 权限问题（builder/cache 基线镜像已由 GITHUB_TOKEN 推送成功，ISS-004/005）；不是 workflow 未触发（CHG-007 已证 push 可用）。

| 类型 | 内容 | 责任人 | 何时执行 |
|---|---|---|---|
| 临时措施（止痛） | 无；不把 `push-ok` 当 digest，不伪造本地载荷 | zeek.zhao | — |
| 永久措施（治因） | 增加 `actions/download-artifact@v4` 取 S5 制品 `cache-payload`（含 `downloads/`、`sstate/`），缺失/空目录即 `::error` + exit 1；删除仓库内默认路径；`docker push` 与 `imagetools inspect` 失败即 job 红，digest 只取真实 inspect 输出；manifest 用 `actions/upload-artifact@v4` 以 `yp-cache-slices-manifest` 上传；summary 打印制品名与每片 digest | zeek.zhao | T3 |

- 如果只做了临时措施，后续项编号：不适用。
