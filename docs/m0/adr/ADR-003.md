## 1. 背景

S3 要建立构建容器，必须先定基础镜像的 Ubuntu 版本。版本选错会导致 Yocto 官方不支持或宿主/容器不一致，影响可复现性。

## 2. 可选方案

| 方案 | 做法 | 优点 | 代价 | 结论 |
|---|---|---|---|---|
| A | `FROM ubuntu:24.04`（LTS） | Yocto 6.0 官方支持矩阵明确列出；与宿主 Ubuntu 24.04.3 一致；可直接安装 pipx+kas | 需按官方包列表装 python3-websockets 等 | 采用 |
| B | `FROM ubuntu:22.04`（LTS） | 亦受支持 | 与宿主版本不一致，增加可复现变量；属另一档依赖集合 | 否 |
| C | main 的四版 Dockerfile | 复用历史 | 与 M0 单一 wrynose 系列目标不符；复制兼容层违反约束 4 | 否 |

## 3. 决策与理由

- **选定方案**：A。
- **关键理由**：官方依据——Yocto 6.0 `system-requirements.html`「Supported Linux Distributions」列出 Ubuntu 24.04 (LTS)；实测宿主为 Ubuntu 24.04.3 LTS，二者一致，减少变量。
- **被否方案的原因**：B 引入宿主/容器版本差异；C 复制多版本兼容层，违反约束 4 且无法用 M0 验收命令覆盖。

## 4. 影响面

| 维度 | 影响 |
|---|---|
| 依赖基线 | apt 包列表按 Ubuntu 24.04 官方段；必装 `python3-websockets` |
| 工具 | pipx 安装 kas（官方推荐），容器入口 PATH 含 `~/.local/bin` |
| 镜像标签 | `yp-builder:wrynose-m0` |
| 门禁 | Dockerfile lint / 构建检查需断言 `FROM ubuntu:24.04` |

## 5. 何时复看

- 触发条件：Yocto 上游发布新 LTS 支持或 wrynose 系列升级基础镜像要求；复看须开 CHG 变更依赖基线。
