# ADR-004 · kas 目录结构与分层策略

| 项 | 值 |
|---|---|
| 编号 | YP-M0-ADR-004 |
| 状态 | Approved |
| 日期 | 2026-11-25 |
| 关联 | DES-002、RV-002 |

## 背景

需要建立 kas 单一入口，既要集中管理 repos 版本与通用变量，又要支持 dev/prod/dev-kernel/ci 四种目标差异，且每次 dump 必须确定性一致。

## 决策

采用四层结构：`yp.yml`（顶层入口，include base + 默认 machine）→ `base.yml`（repos 全 commit pin + 变量默认值）→ `machines/qemux86-64.yml`（唯一 machine）→ `editions/*.yml`（仅写差异变量）。入口组合用 `kas/yp.yml:editions/<name>.yml`。

## 理由

- 变量只在 base 定义默认、edition 只写差异，避免三处重复导致 dump 漂移。
- repos 全部 commit pin（不用裸 branch），保证两次 dump 逐字节一致。
- meta-yp-distro 走本地相对路径，换机器可用。

## 后果

- 新增目录 `kas/`，不触碰 main 参考的多版本兼容结构。
- edition 差异变量需用 `??=` 或显式覆盖，评审需检查重复定义。
