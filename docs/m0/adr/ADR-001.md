# YP-M0-ADR-001 · 发行版层的兼容性策略

| 版本 | v1.0 |

| 决策日期 | 2026-11-24 |

## 1. 背景

S1 要建立发行版层骨架，必须先定 `LAYERSERIES_COMPAT` 与 distro conf 的组织方式。不定会卡住 `layer.conf` 的具体取值，且一旦写错会引入与 M0 无关的多版本兼容逻辑（约束 4 明令禁止复制 main 的四版兼容层）。

## 2. 可选方案

| 方案 | 做法 | 优点 | 代价 | 结论 |
|---|---|---|---|---|
| A | `LAYERSERIES_COMPAT = "wrynose"` 单值；distro conf 仅 `require conf/distro/poky.conf` | 与 M0 单一发行版目标一致；结构最小、可审计；验收命令可覆盖 | 将来若要多系列需重新决策 | 采用 |
| B | 复制 main：`"dunfell kirkstone scarthgap wrynose"` 四值 + `yp-compat.inc` | 复用已有兼容层 | 引入 M0 范围外的兼容分支逻辑、CVE 库、eSDK workaround，违反约束 4；S1 验收命令无法覆盖 | 否 |

## 3. 决策与理由

- **选定方案**：A。
- **关键理由**：M0 目标与验收判据全部围绕 wrynose 单一系列；单值 `LAYERSERIES_COMPAT` 可被「grep 断言取值唯一」直接验证，符合 ISO 对齐的可审计要求。
- **被否方案的原因**：方案 B 的四版兼容层是 main 分支为多发布系列维护的历史资产，本孤立分支按约束 4 只借鉴 kas/Docker/Actions 的组织方式，不复制兼容层；复制会导致大量无法用 M0 验收命令证明正确的代码。

## 4. 影响面

| 维度 | 影响 |
|---|---|
| 变量 | `LAYERSERIES_COMPAT_meta-yp-distro` 锁定为 `wrynose`；`DISTRO` = `yp-wrynose` |
| 目录与脚本 | 新增 `meta-yp-distro/conf/`；不引入 `conf/distro/include/yp-compat.inc` |
| 门禁 | 静态验收增加「无 dunfell/kirkstone/scarthgap 字样」断言 |
| 已产出镜像/缓存 | 无（S1 阶段尚无产物） |

## 5. 何时复看

- 触发条件：PRD 要求支持 wrynose 之外的第二发行版系列，或上游 wrynose 系列字符串变更。复看时须新开 ADR 并走 CHG 单，不得直接追加到本层。
