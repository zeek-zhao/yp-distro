## 追加记录 · T4 UID 参数化（文档先行）

| 项 | 值 |
|---|---|
| 对象 | `scripts/bootstrap.sh`、`scripts/preflight.sh`、`docs/runbook-new-machine.md` §5.2 |
| 输入 | 两脚本新增 `--uid <n>`、`--gid <n>`，默认取当前用户 `id -u`/`id -g`；`JENKINS_UID/JENKINS_GID` 保留为镜像默认与文档默认 |
| 失败模式 | 目标 UID/GID 与当前用户不一致且当前非 root → exit 2，给出 sudo 路径与重建 `yp-builder:local` 路径；preflight 检查「目录属主 == 目标 UID 且当前用户可写」，不一致 → exit 2 + 具体修复命令；禁止静默 chown 到不可写状态 |
| 验收命令 | 当前用户为 1000 时 `bootstrap.sh`/`preflight.sh` 行为与 M0 验收命令一致；模拟目标 UID≠当前 UID（非 root）必须 exit 2 且打印两条路径 |
| 回滚 | `git revert`；不改变 `threshold.conf` 的 JENKINS_UID/JENKINS_GID 默认值 |

当前用户为 root 时视为「sudo 路径」：允许把目录 chown 到显式 `--uid/--gid`，因为 root 仍可写，不构成自锁；非 root 时一律拒绝并给修复路径。
