## 2. §1 开工复现（只读，问题存在性）

以 uid1234 在 `/tmp/uid6` 隔离探针（真实命令与输出）：

```text
DEFAULT_BOOT_RC=2
  ERROR[2] UID_MISMATCH: 目标 UID:GID=1000:1000 与当前用户 1234:1234 不一致。
  （打印两条路径：sudo --uid 1000 / 重建 yp-builder:local）
EXPLICIT_BOOT_RC=0
  INIT downloads marker=.../dl/.yp-volume ; OWNER_OK .../dl (1234:1234)
  INIT sstate   marker=.../sstate/.yp-volume ; OWNER_OK .../sstate (1234:1234)
  stat → 1234:1234 /tmp/uid6/dl , 1234:1234 /tmp/uid6/sstate
EXPLICIT_PF_RC=0
  OK role=downloads owner=1234 writable=yes ; OK role=sstate owner=1234 writable=yes
```

结论：脚本逻辑正确（显式 UID 可用、默认 1000 会拒绝），**问题在文档命令**——runbook §5.2/test prompt §4.2 的路径 B 漏显式 UID、步骤 7 写死 GHCR 镜像（ISS-031）；当前判据「两层解包」与 GHCR two-stage 口径（ISS-032）。
