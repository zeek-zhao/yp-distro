## 4. UID 路径决策（§4）

```
id -u = 0 ; id -g = 0
threshold.conf: JENKINS_UID=1000 / JENKINS_GID=1000
```

§4.2 隔离探针（不带 --uid，min-free 0）：**exit 0，属主 0:0** → **复现 K-1（ISS-022，P1）**。默认路径会把卷建在 0:0，容器 entrypoint 要求 1000，会拒绝启动。

**决策：路径 A（root/sudo，卷保持 1000）**。已按 CHG-014 修复默认目标（见 §10 缺陷处理），本轮正式卷及后续所有 preflight/容器命令显式带 `--uid 1000 --gid 1000`。

**K-3 事实（GitHub API 匿名）**：release `m0-s5-payload-full` 资产数 **9**：`cache-full.part-00..07` + `cache-full.sha256`，**无** `cache-full.manifest.json`（与 CHG-013 声称不符，ISS-024）。
